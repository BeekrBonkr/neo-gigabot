# Images

Overlays and meme templates the image commands open at run time.

| File | Used by | Source |
|---|---|---|
| `petpet.png` | `/animate pet` | The hand sprite sheet from the original petpet generator, benisland.neocities.org/petpet |
| `changemymind.jpg` | `/memegen changemymind` | The change-my-mind photo with a blank sign, as used by memegen.link (github.com/jacebrowning/memegen, `templates/cmm`) |
| `drake.jpg` | `/memegen drake` | The left column of the Drake Hotline Bling template from imgflip (imgflip.com/memetemplate/Drake-Hotline-Bling) |
| `triggered.png` | `/animate triggered` | The TRIGGERED label from Dank Memer's image generator (github.com/DankMemer/imgen, MIT) |
| `respects.jpg` | `/memegen respects` | The Press F to Pay Respects scene, from imgflip (imgflip.com/memetemplate/Press-F-to-Pay-Respects) |
| `whodidthis.png` | `/memegen whodidthis` | The WHO DID THIS frame from Dank Memer's image generator (github.com/DankMemer/imgen, MIT) |
| `wheeze.png` | `/memegen wheeze` | The Wheeze comic, from imgflip (imgflip.com/memetemplate/85219185/Wheeze) |
